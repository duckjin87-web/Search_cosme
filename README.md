# 화장품 표시사항 사전검토 시스템

생산 전 제품명으로 조회하면 판매채널에서 해당 제품의 면별 사진을 수집하고, 후면 중심으로 표시사항을 추출해 체크리스트로 보여주는 사내 참고용 시스템.

> **사전 참고용 도구입니다. 최종 확인은 반드시 실물 또는 도면 기준으로 합니다.**

---

## 무엇을 하는가

| | |
|---|---|
| 주 용도 | 표시사항·규격 사전 검토 |
| 조회 기준 | 제품명 |
| 기간 기준 | **이미지 수집일** (제품 출시일 아님) |
| 대상 카테고리 | 용기형(6면), 튜브(전후좌우 + 상단·하단) |

1. 제품명으로 조회하면 채널별로 제품 이미지를 수집한다
2. 비전 모델이 각 이미지의 면(전·후·좌·우·상·하)을 분류한다
3. 후면을 중심으로 OCR + 상세페이지 텍스트로 표시사항을 추출한다
4. 화장품법 기재사항 룰셋으로 항목별 체크리스트를 만든다
5. 수집일 단위 스냅샷으로 누적해 리뉴얼 전후 변경을 비교한다

## 설계의 핵심 원칙

**판독불가와 면 미확보를 "없음"으로 뭉개지 않는다.**
표시사항 검토에서 가장 위험한 것은 누락 오판이다. 네 가지 상태(있음 / 없음 / 판독불가 / 면 미확보)를 끝까지 구분해 전달한다.

**모든 데이터에 출처를 붙인다.**
이미지와 추출 텍스트 전부에 채널 · 원본 URL · 수집일을 부착한다. 채널 간 값이 다르면 자동 선택하지 않고 충돌로 표시한다.
