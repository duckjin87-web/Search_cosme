## 판정 상태

| 코드 | 표기 | 의미 |
|---|---|---|
| `ok` | 있음 | 해당 면에서 항목 확인 |
| `none` | 없음 | 면은 확보됐으나 항목 미확인 |
| `unreadable` | 판독불가 | 면은 확보됐으나 해상도 등으로 판독 실패 |
| `face_missing` | 면 미확보 | 해당 항목이 있어야 할 면 자체가 없음 |

### 핵심 규칙

**`unreadable`과 `face_missing`을 `none`으로 뭉개지 않는다.**

"없음"은 "확인했는데 표기가 없다"는 판정이고, 나머지 둘은 "확인하지 못했다"는 상태다. 이 둘을 섞으면 실제로는 표기가 있는 제품을 누락으로 오판하게 된다. 표시사항 검토에서 가장 위험한 실패 유형이다.

## 판정 부가 정보

각 항목은 상태 외에 다음을 함께 기록한다.

| 필드 | 설명 |
|---|---|
| `value` | 추출된 실제 값 (있을 때) |
| `source` | `ocr` 또는 `detail_text` |
| `conflict` | 채널 간 값이 다를 때 `true` |
| `note` | 출처 면, 충돌 내역, 이전 수집분 대비 변경 등 |

### 충돌 처리

OCR 결과와 상세페이지 텍스트가 다르거나, 채널별 값이 다른 경우:

1. 자동으로 하나를 선택하지 않는다
2. `conflict: true`로 표시하고 양쪽 값을 모두 보존한다
3. 화면에 "채널 간 표기가 서로 다름 · 확인 필요"로 노출한다
